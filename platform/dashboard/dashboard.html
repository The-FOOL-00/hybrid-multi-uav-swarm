🔀
Hybrid Architecture
No existing Webots simulator fuses global planners with reactive avoidance in a pluggable, benchmarkable framework.
🏭
Factory Pattern
Algorithms swap at runtime via YAML config. No code change needed to compare A* vs RRT vs Dijkstra.
📐
Formal Metrics (M01–M16)
16 metrics with ground-truth vs proxy designation. Rigorous scientific measurement, not ad-hoc logging.
🧪
Publication-Grade Pipeline
Every experiment produces statistically analysable data leading directly to a peer-reviewed paper submission.
